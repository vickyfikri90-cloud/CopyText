# 2026 CopyText

**Role:** Solo builder  
**Status:** Building MVP  
**Platform:** macOS 13+ (AI Mode requires Apple Intelligence)

## What it is

Menu bar macOS app that turns screenshot text into clipboard-ready text in one shot — no window, no cloud, native OCR.

## Problem

Text on screen often can't be selected: Figma, YouTube, PDFs, images, presentations. Copying it is slow or impossible.

## Goal

Make extracting text feel as fast as native copy & paste.
